# TriAnSec Benchmark & Telemetry Suite

This repository contains the official benchmark harness, asynchronous workload generators, multi-run evaluation orchestrators, and empirical telemetry datasets supporting the research paper *"TriAnSec: A Stateful, Behavior-Driven Security Middleware for Application-Layer API Business Logic Protection"*.

> **Note:** This repository hosts the experimental evaluation scripts and raw telemetry logs for peer-review verification. The full TriAnSec ASGI middleware package and core engine will be made available upon formal publication.
